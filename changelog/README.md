# MCP Server Release History

This directory contains detailed release notes for the Guardrail Hub MCP Server — one Markdown document per release. It is dedicated solely to MCP Server release history.

Documentation structure:

- [`../CHANGELOG.md`](../CHANGELOG.md) — canonical project history. The v0.1.0 entry is intentionally comprehensive as the founding release; from v0.2.0 onward, each release gets one concise summary section linking to its detailed notes here.
- `changelog/vX.Y.Z.md` — complete notes per release (overview, highlights, new features, platform architecture, improvements, bug fixes, breaking changes, technical notes).

Future versions (v0.2.0, v0.3.0, v1.0.0, …) follow this structure.

## Releases

- [v0.1.0](v0.1.0.md) — 2026-07-19 — First release: MCP execution platform with OWASP ZAP scanning as the first supported capability.
